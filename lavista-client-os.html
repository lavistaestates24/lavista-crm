Full System — Build Roadmap
Each phase builds on the previous phase's data (clients, calendar). This is an honest status view — what's live, what's next, and what real API keys/setup each stage requires.
1
Client Management + Content Calendar LIVE — in this tool
Add a client, set the package, and a date-wise post/reel calendar is generated automatically with optimal time slots. Data is currently saved in this browser (localStorage).
2
Auto-Posting to Instagram/Facebook LIVE
Posts and reels are automatically published via the Meta Graph API at the scheduled date/time. Each client's Instagram Business account must be connected (via Facebook Business Manager token), and a scheduled server job (Supabase Edge Function) checks and publishes due content.
3
Meta Ads Campaign Automation PLANNED
Select a client, set a daily budget → the Meta Ads API auto-creates a lead-gen campaign. Audience/creative switches based on cost-per-lead rules. This is a rule-based engine reacting to performance data, not self-learning AI. Requires Meta Ads account access.
4
WhatsApp Lead Verification Bot NEXT
As soon as a new lead arrives, the WhatsApp Business Cloud API sends an automatic first message plus 2-3 qualifying questions (budget/location/timeline). Based on replies, the lead is auto-tagged: Hot / Warm / Cold / Fake. Message-based verification only, no calling. Requires WhatsApp Business API approval and a number.
5
Daily Lead → Excel Auto-Sync + Dashboard PLANNED
Each night/morning, leads (with WhatsApp verification tags) auto-populate into the client's sheet (Supabase → Google Sheets or Excel export), along with cost-per-lead and lead-quality summaries — this data feeds the Phase 3 ads automation.
