Poora System — Build Roadmap

1
Client Management + Content Calendar LIVE — is tool mein
Client add karo, package set karo, auto date-wise post/reel calendar ban jaata hai best-time slot ke saath. Data abhi is browser mein (localStorage) save ho raha hai.
2
Auto-Posting to Instagram/Facebook NEXT
Meta Graph API se calendar ki date/time pe khud post/reel publish ho — iske liye har client ke Instagram Business account ko connect karna hoga (Facebook Business Manager se token) + ek server (Supabase Edge Function jaisa tumhare attendance system mein hai) jo scheduled time pe API call kare. Graphics/reel file upload karna abhi manual rahega — AI se poora video render karna alag heavy project hai.
3
Meta Ads Campaign Automation PLANNED
Client select karo, daily budget daalo → Meta Ads API se lead-gen campaign auto-create. Cost-per-lead rules ke basis par audience/creative switch (agar zyada cost ho). Ye "AI khud seekh kar strategy badalta hai" nahi — ye "agar-to" rule-engine hai jo performance data dekh kar action leta hai. Meta Ads account access chahiye hoga.
4
WhatsApp Lead Verification Bot NEXT
Naya lead aate hi WhatsApp Business Cloud API se automatic pehla message + 2-3 qualifying questions (budget/location/timeline). Reply ke basis par lead auto-tag hota hai: Hot / Warm / Cold / Fake. No calling — sirf message-based verification. WhatsApp Business API approval + number chahiye.
5
Daily Lead → Excel Auto-Sync + Dashboard PLANNED
Har raat/subah leads (with WhatsApp verification tag) client ke folder ki sheet mein auto-populate (Supabase → Google Sheets ya Excel export), saath mein cost-per-lead aur lead-quality summary — yahi data Phase 3 ads automation ko feed hota hai.
